# Nifty 50 Sector Rotation & Anomaly Detection

## Overview

An end-to-end financial analytics project focused on identifying sector leadership trends, volatility shifts, and unusual market activity within Indian large-cap equities.

Using Python, SQL, and Power BI, this project transforms raw stock market data into actionable insights for portfolio monitoring and sector-based decision making.

---

## Business Objective

This project helps answer key investment and analytics questions:

- Which sectors are leading or lagging during different market phases?
- Which stocks are experiencing abnormal volatility?
- Where are unusual price or volume spikes occurring?
- How can historical sector rotation improve allocation decisions?

---

## Tech Stack

- **Python** – Pandas, NumPy, yFinance
- **SQL** – MySQL queries, ranking, window functions
- **Power BI** – Executive dashboards & visualization
- **Jupyter Notebook** – Analysis workflow

---

## Dataset

- Nifty 50 selected stocks across major sectors
- Daily OHLCV market data
- Historical period: **2021 – 2024**
- Data source: Yahoo Finance API

---

## Key Features

### Data Engineering
- Automated stock market data extraction
- Structured raw-to-analysis pipeline
- Cleaned and transformed historical market data

### Analytics
- Rolling returns and volatility calculations
- Sector-wise comparative performance analysis
- Quarterly sector rotation tracking
- Statistical anomaly detection using deviation thresholds

### Visualization
- Interactive Power BI dashboard
- Executive summary metrics
- Sector performance comparison charts

## Key Insights

- Defensive sectors outperform during uncertain phases
- Cyclical sectors lead during bullish momentum periods
- Volatility spikes often precede sharp price movement
- Sector leadership rotates over time rather than remaining constant
